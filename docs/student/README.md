# Student Documentation

These guides explain the practical steps for working with this Python
assignment from your computer and GitHub. Start with
[STUDENT_README.md](../../STUDENT_README.md), the primary source of the
assignment requirements, then use the guide that matches what you are trying
to do.

## Guides

| Guide | Consult it when you need to... |
|---|---|
| [Initial Git and GitHub Setup](github.md) | Install Git, configure your identity, sign in to GitHub, and connect your local repository. Git Credential Manager is the preferred sign-in method. |
| [Everyday Git Workflow](git-workflow.md) | Review changes, save focused commits, pull instructor-provided updates, push checkpoints, and recover from common local mistakes. |
| [Student Setup Guide](setup.md) | Install Python, install `requirements.txt`, and run pytest. |
| [Development Cycle](development-cycle.md) | Follow the normal workflow from understanding requirements through development, testing, committing, final review, pushing, and monitoring CI. |
| [Writing a Professional README.md](writing-a-readme.md) | Write clear, accurate documentation for a public portfolio repository. |
| [Publish Your Completed Assignment](publishing.md) | Publish approved work to a public repository after the semester, after checking for private material and obtaining permission. |

## Recommended order

1. Read [STUDENT_README.md](../../STUDENT_README.md) to understand the
   assignment requirements and deliverables.
2. Read [Initial Git and GitHub Setup](github.md) if Git is not installed or
   connected to your GitHub account.
3. Follow the [Student Setup Guide](setup.md) to install dependencies and check
   that pytest finds the starter suite.
4. Use [Everyday Git Workflow](git-workflow.md) and the
   [Development Cycle](development-cycle.md) while completing the assignment.
5. After your instructor approves publication, use
   [Writing a Professional README.md](writing-a-readme.md) to document the
   finished project.
6. After the semester—and only with instructor permission—read
   [Publish Your Completed Assignment](publishing.md) before making course work
   public.

Public publication is optional. Never publish solutions, hidden tests, private
course files, secrets, or another student's information without permission.
